# Aemeath Desktop Pet · 爱弥斯像素桌宠

面向 Windows 的《鸣潮》爱弥斯像素桌宠项目。造型贴近游戏内像素小爱，待机参考实机演示，计划支持鼠标拖动反馈及 Codex 任务状态联动。

**当前阶段：需求与技术验证。尚无可运行版本。**

## 产品范围

- 外观：游戏内像素小爱的紧凑头身比、粉发、蓝色头饰和羽状装饰。
- 待机：参考游戏动作制作适合桌面的小幅动画。
- 交互：拎起、拖动、松手各有反馈。
- 任务状态：工作、等待用户、完成、失败能区分。
- Windows 桌面：透明背景、拖动、位置恢复、缩放、退出入口。

独立桌宠是推荐方案；Codex 内置兼容皮肤作为备选。平台方案将在技术验证后通过 ADR 明确，不修改 Codex 安装包。
