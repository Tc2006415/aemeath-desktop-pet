# ADR 0001：桌宠运行方式

状态：提案，未接受。

## 背景

用户需要游戏内像素爱弥斯、丰富待机、拖动反馈及 Codex 任务状态联动。已查明当前 Codex 内置自定义图集有固定动画槽，待机使用 6 帧；没有确认任意多套待机和拖拽动画的可配置入口。

## 候选

1. 内置兼容皮肤：保留原有整合，但需要精简动作，不能承诺完整满足行为需求。
2. 独立 Windows 桌宠：自行控制动画和拖动；任务联动作为独立适配层，必须验证真实事件来源。

推荐第二项，尚未将推荐当成用户明确选择。当前可开展两种方案的只读技术验证和规格提案，不能修改 Codex 安装包。

## 接受条件

- 程序任务说明可用工具链、透明窗口和多 DPI 的验证路径。
- 联动任务说明是否存在受支持且可访问的状态来源；未找到时给出诚实的独立运行降级方案。
- 素材任务提供游戏风格的帧尺寸、动作容量和播放需求。
- 统筹结合用户选择接受本 ADR 后，再确定实现技术栈和共享接口。
