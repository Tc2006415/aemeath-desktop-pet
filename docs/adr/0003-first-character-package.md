# ADR 0003：首批角色素材与交互

状态：已接受阶段范围，2026-09-16。用户在第1–4步初步验收后明确要求进行下一步。

## 前置验收

用户反馈上轮清单全部通过，记录为用户人工验证：显示、循环/单次播放、拖动/松手重抓、缩放、窗口外点击、错误反馈和退出。并非代理独立实测。首次启动坏素材及讲述人仍待验，不将其扩写为用户已执行。

## 第5步范围

采用已选游戏像素小爱造型，以 assets/concepts/aemeath-game-style-v2.png 为参考，保持粉发、蓝色头饰、两侧羽状装饰、紧凑比例。制作真实透明基准帧，视觉检查后扩展 neutral、idle-soft、idle-smile、drag-pickup、drag-hold、drag-release。idle-smile是游戏参考改编，其余按素材规格的来源声明，不声称完整游戏动作复刻。

ART负责 assets/characters/aemeath-v1/ 与自身制作记录，使用内置imagegen生成或编辑角色图片；不能用程序画占位角色或仅平移整图冒充完整动作。既有96×104/锚点(48,94)/RGBA/二值alpha契约继续有效。生成输出不符合要求时明确说明，不偷偷放宽加载器。图片身份/尺寸转换方式按工具规则执行；外观确认留给用户，不把文件可解析等同视觉验收。

DEV负责表现协调与宿主接入。neutral回退；正常待机默认idle-soft，每15秒具备idle-smile时播放一次，结束回idle-soft。按下立即pickup，仍抓取则hold；早松手或捕获丢失转release；release结束回当前待机；release期间再抓立即pickup。所有时长读取素材，缺失或停用动作不得卡住覆盖。时钟/随机等待不加入业务状态模块。模拟及真实任务状态均不接入，来源仍未知。

诊断手动播放保留为可选模式，原包仍可用于回归；角色包先通过显式包目录加载和自动交互模式验证，PM在素材视觉和格式检查完成后才决定将其作为默认素材打包。

## 验证

协调器可控时钟测试：pickup结束进入hold、快速松手、失去捕获、release中再抓、缺动作、旧完成回调、单次笑脸回基础待机。复用已通过加载器/几何测试，不穷举DPI。每条新角色动作做帧尺寸/alpha/时长/锚点和视觉检查；用户确认外观及真实播放。未完成的帧不计完成，不以重复文件充数。实际不需25张独立图片，但需真实有意义的姿态变化。

发布、任务状态联动、持久化、多屏支持及外观编辑器不在本轮范围。任务卡直接发各任务，具体交付提交后由PM和QA验收。
