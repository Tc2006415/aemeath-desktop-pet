# ART024制作方法影响说明（仅提案，未实施）

需求已冻结：A为用户选v2精确字节；同一组羽片身份与长度层次、固定翼根、内外协调且左右同相。B/C约2/4px是幅度目标，不允许短翼或高位移。脸身头饰、原1400/1200ms和已认可大幅上扬保持。本说明不重验A、不生成或合成、不重跑旧帧/入口/格式检查。

## 三种原因应分开

|原因|现有证据能支持什么|不能据此断言什么|
|---|---|---|
|源图羽形变化|两张B原始source仍可见两侧完整三羽组，形状/长度层次与A有视觉差别；B2源并非只剩最终合成图那样的短块。|没有已配准的源轮廓测量，不能将合成后实心182→10/116直接解释为源图把羽片缩短了同样比例。|
|源图整体配准偏移|1205×1305源经过整画布最近邻映射，没有任何整数配准；提示词反复要求原位置，但生成器仍重绘了非翼结构和翼部位置。画布比例近似相同不证明角色内部位置相同。|尚无多个固定标志给出一致整数偏移的现有记录，不能认定全部问题都是纯平移，也不能直接指定历史(0,+5)一定适用。|
|固定mask裁切|compose.py先映射整画布，再只复制原位置mask内RGBA，mask内透明也覆盖A。B1完整源翼与合成后两个5px孤块的对照，明确说明大量翼像素没有被mask保留；B2同样不能将最终短块与原源羽形混为一谈。|不能因mask外差分0就认为mask合成视觉正确；保护通过与源翼完整保留是两件事。|

因此，**是的：未配准的整画布映射会让本应采用的翼落在固定mask外，随后被合成步骤排除**。最近邻本身做的是采样，不会自动对齐翼根；直接造成硬裁切的是后续mask。B1证据最明显，B2也有位置/裁切混杂，现有材料不足以量化三种因素各占多少。先前“生成源不能保持羽长”的归因过强，应收窄为“当前未配准合成没有保住A羽片身份”。采样/alpha阈值可能影响细像素，但未有证据证明它是本轮主要原因。

依据：[B1提示](art024-B-v1-prompt.txt)、[B2提示](art024-B-v2-prompt.txt)、[转换与合成顺序](art024-compose.py)、[既有结果](art024-check-report.json)、B1/B2的source/donor/candidate原文件。没有新增测量或试算。

## 可执行的方法调整，供PM裁决

1. **先处理坐标系，再评价新姿态。** 后续首先只评估现有B2 donor与A是否存在单一整幅整数偏移：以未要求动作变化的多个标志（冠尖、脸/身体中心、脚底）及左右翼根共同约束，不能只盯翼尖拟合2px。若标志互相矛盾、角色比例或局部结构改变，单一平移不能修复，就停止该源；不旋转、拉伸、分别移动两翼，也不扩大mask吞进衣发。
2. **整数整幅donor配准可以使用。** 用户早已授权，ART021等记录也使用过；它校正的是生成图与固定底的坐标关系，最终A/脸身不动，不是用程序生成扇动姿态。ART024把“禁止整体移缩造动作”扩大理解为“零配准”，并在提示和脚本中写死no translation，混淆了二者，应纠正。具体偏移必须有共同标志支持，不能无证据复用+5或通过平移造出B/C幅度。
3. **生成前固定位置与尺寸基准。** 若现有源无法挽回、PM另许生成：以A完整画布为唯一造型基准；必要时只做等比例最近邻参考放大，保留所有透明边距，不裁角色、不按包围盒居中。预先标定同一坐标系的翼根、三羽尖/分叉和羽长层次，给B/C同一份位置与尺寸表，2/4px只约束外尖轻抬。先固定这些输入和允许的整幅配准规则，再生成；提示词无法保证工具逐像素遵守，不能把坐标文字当成已完成定位。
4. **配准后才局部合成。** 在已批准包络内审视实际扫过轮廓与mask，完整保留该姿态羽片，根部/衣袖/发尾/身体保护不变。只针对新donor确认羽序、长度层次及协调运动；不重新审美验收A，也不重跑旧11帧/16入口。必要的新合成保护/格式检查只在产生新候选后做一次，不以重复旧检查替代制作。

范围变化：本轮仍无实施授权。建议PM先裁决一次**现有B2的整幅配准可行性及必要时一次局部重合成**，而非先新增生成。已有整数对齐授权无需重新向用户索取，但这会新增ART024已用尽两版以外的合成版本，需PM明确给出处理范围和上限；不是偷偷续版。若配准不可行，再决定是否需要新源及怎样固定输入，不盲重置次数。A、正式包、旧动作和时序均不变。
