# ART030 拿起动作v2初版 · 待用户审核

交付离线中文 `art030-demo.html` 与 `art030-frames/` 四张实际PNG。只拿起360ms，终点为新v2持握入口静止，拖动循环待下一项；演示复位不是放下动作。正式素材/manifest/宿主未改。

## 制作与来源

以旧pickup“松腿惊讶→短暂收腿→松腿持握”的含义为参考，未复制旧身体/翼PNG。新身体采用内置imagegen2次（上限4），loose与tuck；整体合成1版（上限2）。使用当前A的局部[24,56,72,104)48方格精确24倍1152方图作参考，实际源1254方图按像素中心近邻映射48方格放回(24,56)，alpha128、额外偏移0。两源颈胸位于同一原参考固定位置，未程序平移/旋转角色。新身体姿态是真实生成，源头脸/外翼变化不采用。

允许身体x35..60/y75..98和既有222像素眼口mask；其他头饰、粉发、脸外轮廓、颈上固定。眼口复用ART011已有imagegen惊讶donor；末帧复用ART027半闭眼和中性嘴部。羽翼完整复用ART026 A像素，与body mask不相交，未回流旧翼。具体mask/源SHA/表达来源SHA见art030-mask.json和build-report。

四项保持：neutral80（精确A）/surprise80（新loose+惊讶眼口）/pickup100（新tuck+惊讶眼口）/hold-entry100（新loose+认可半闭眼）。脚底分别为原A93、松腿98、收腿92、末帧98；这是腿姿变化，头部位置固定，不称整角色悬浮。松腿略不对称，衣服高光/手臂细节有生成差异，初版以用户观感为准。

## 来源入口与真实风险

演示默认自动待机组合；可选择基础A、轻扇B/C、半闭/闭合眨眼、wink歪头+衣摆、B轻扬、C上扬。模拟按下直接记录最近显示的源PNG并立即开始neutral80，不等待当前动作结束。页面并列实际源快照与首项A，保留原首帧切换风险。

实际源→A的RGBA变化像素：A0、B186、C224、半闭201、闭合204、wink+上扬2256、B+轻扬232、C+上扬270。它们表示差分，不等同像素位移或无缝评级。wink回正/翼及衣摆复位可见，尚未解决。拿起中翅膀使用固定v2 A，不宣称延续源B/C相位。

如用户要求进一步消除入口突跳，建议PM另立仅入口衔接的范围：针对B/C翼、眼闭合和wink头姿三类入口，先评估保留按下源快照作为首80ms，再为到surprise的新姿转接绘最多1个专用回正/收翼中间帧，并明确是否允许替换现有四项之一或增加时长。仅保留源80ms会把突跳延后，不能单独宣称修复；wink类尤其需要真实回正姿态。此处只是具体提案，本轮没有实施或修改正式360ms契约。
