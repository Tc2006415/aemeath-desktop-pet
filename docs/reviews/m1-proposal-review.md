## 2. 分类与总体判断

- **真实冲突**：同一前提下，两份提案要求不能同时成立的行为。此次未确认这样的直接矛盾；不把不同细化程度或候选方案冒充冲突。
- **正常未决项**：提案明确未冻结，或缺少实现所需边界。未决属于正常 M1 输入，但其中部分仍阻塞 M2 开始或验收。
- **非阻塞建议**：提高覆盖或可读性，不影响当前文档交付；在相关阶段前复核。

拖动视觉覆盖与业务状态分离、终态不能由动画结束推断、重复/旧事件不触发新庆祝、未知来源降级、概念图不是成品，四份提案方向一致。ART 的中性姿态不等于业务 idle，与 INT 的终态保留及 QA 的 unknown 标识要求可同时成立。INT 的 5 秒提示窗口与 ART 的 1100/1200 ms 动画长度分别描述资格窗口与播放时长，也不是数值冲突；两者的边界衔接尚未定。

**M2 尚未具备实施准入依据**：ADR、最小素材/状态契约及工程授权未接受。真实 Desktop 来源未证实阻塞 M4，不能因此判定显式模拟的 M2 永久不可做；是否分开推进由 PM 接受并派单。本报告不自行批准降级。

## 6. 给 PM 的最小决策包

建议先裁决以下五组，而不是要求各任务各自确定字段：

1. U01：运行方式、优先验证技术栈、工具链及样机授权；实际验证失败时的回退流程。
2. U02/U03/U04/U09：最小模拟状态契约、显示任务范围、release 期间重计算、提示消费归属与计时边界。真实源未到位时仍明确标 mock/unknown。
3. U05/U06/U07：固定像素锚点、导出倍率和 DPI 坐标链、加载格式/上限及错误退出路径；只冻结实施所需最小契约。
4. U08：是否接受 M2 独立/模拟与 M4 Desktop 真实接入分开验收，以及 completed 仅指当前轮次的展示含义。
5. U01/U06 与 QA D7：指定实机/DPI/无障碍/干净环境覆盖责任和验收判据；没有设备或工具链时标阻塞，不用文档检查替代。
