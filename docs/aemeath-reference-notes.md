## 本机 Codex 调查

安装版本：OpenAI.Codex_26.903.9818.0_x64。

只读检查应用资源确认：

- 设置中有 Custom pets / Create / Refresh / Open folder 入口。
- 本地加载器读取 pets 下的 pet.json，兼容 avatars 下的 avatar.json。
- 配置字段包括 displayName、description、spriteVersionNumber、spritesheetPath。
- 第二版图集为 1536×2288，8 列、11 行，每格 192×208。
- 图集每行所需帧数：[6,8,8,4,5,8,6,6,6,8,8]。
- 已见动画状态：idle、running-left、running-right、waving、jumping、failed、waiting、running、review。
- 第 9、10 行（从 0 计数）用于方向注视帧。
- 已读到的通用动画组件把 idle 映射到固定 6 帧。其他状态先重复其动作，再接待机序列。

因此：自定义皮肤可行，但完整多套随机待机、专用拖拽动画，以及任意更改状态触发逻辑，尚未确认有公开配置入口。不能承诺只放入图集就能实现所有行为。
