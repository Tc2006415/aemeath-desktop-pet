## 本轮工程范围

C# / WPF / .NET SDK 10.0.401，Windows 11 x64。允许在用户目录部署官方校验过的 SDK，绝对路径调用，不改变系统 PATH。首次部署若版本不可取得，报告具体证据，不自行切换框架。

实现诊断控制窗、透明小窗、单屏拖动、当前 DPI 下 1/2 倍整数物理像素缩放、素材校验与播放器、可发现的键盘退出。诊断包只需 neutral、idle-soft、idle-smile 三动作，采用固定 96×104、锚点(48,94)、透明逐帧 PNG 与 manifest。合成编号/色块是测试夹具，不是角色成品。

程序独占 src/Aemeath.Host、src/Aemeath.Presentation、对应 tests、assets/diagnostic、工程配置、构建脚本及其技术说明；测试独占审查报告及独立验证脚本。共享接口改变先由 PM 裁决，不实现状态模块，不生成爱弥斯正式角色帧，不创建额外任务。

## 必要验证

- 工具链 --info、restore、Release build 成功；播放器边界/循环/单次/取消，素材合法与损坏/越界，坐标转换/抓取偏移采用必要行为测试。
- 真机 H1/H2/H5 与 H4 当前 DPI：可见透明窗口、慢快拖中动画继续、窗口外松手与捕获丢失不残留、矩形外不拦截、错误可见、键盘退出释放进程。真实 UI 无法操作或无证据则记待验，不用程序内部模拟代替。
- 单次到期回 neutral，仅一次结束通知；旧回调不能覆盖新动作；未连接显示未知，诊断来源有标识。
- H3 任务状态联动、角色视觉、持久化、多屏完整支持与 H6 干净环境分发验收不在本次完成声明中。可以构建本地自包含目录用于测试，但不得把开发机启动当成干净环境通过。

## 实施及交接

按工具链/空窗、播放器/加载器、真实窗口/拖动三个可验收增量实现。工程任务编写本地实施步骤并立即执行已授权范围，无需再次请求方向确认。各增量记录真实命令和测试结果。QA 对具体代码提交独立复核，PM 收敛问题后报告第1–4步各自状态。任务卡仍只在任务对话下发。
