# ART029 生成前固定方法

只两腿外侧的深色白边衣摆末端：x34..38与57..61，y87..92；连接行y86固定。两脚位于中央x42..53左右，粉色手尖位于x40..41/54..55附近，不纳入；外侧羽翼与发尾不纳入。60像素mask与ART026翼mask不相交。这里坐姿衣摆极小，轻微折起即可，不为1–2px目标扩大裙身/腿。

参考完整局部矩形[24,56,72,104)48×48，24倍精确1152方图，背景真实alpha；源须方形且同局部边界，按像素中心近邻48方格映射放回(24,56)，alpha128，无变形。生成轻扬与上扬2姿，连接点不移，布料末梢轻折起约1/2px；源看后只mask局部合成。新增imagegen<=3，整体合成<=2。

同翼1400ms时间轴：base0..400，light400..550，upper550..1200，light1200..1350，base1350..1400。上升对齐翼400/550；回落比翼1100/1250各迟100ms；首尾base不跳。没有独立随机衣摆timer。拖动衣摆base，释放按当时翼时钟直接取衣摆相位。眼/wink仅复用认可PNG，原功能timer不受衣摆开关影响。
